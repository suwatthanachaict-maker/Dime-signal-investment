# 🤖 บอทแจ้งเตือนหุ้น → Telegram (สำหรับใช้กับ Dime!)

บอทนี้จะคอยสแกนหุ้นในลิสต์ของคุณตามเวลา แล้ว **ส่งแจ้งเตือนเข้า Telegram**
ว่า *ซื้อ/ขายตัวไหน ที่ราคาเท่าไหร่ เป้าหมาย/จุดตัดขาดทุนตรงไหน* — จากนั้น
**คุณเปิดแอป Dime! แล้วกดส่งคำสั่งเอง** (Dime! ไม่มี API ให้ยิงออเดอร์อัตโนมัติ)

รันบนคลาวด์ฟรีด้วย GitHub Actions → ไม่ต้องเปิดคอมทิ้งไว้

---

## ภาพรวมระบบ

```

        │                         │

        │                         │
        └──────────────►  ส่งเตือนเข้า Telegram  →  📱 คุณกดซื้อใน Dime! เอง
```

## ขั้นตอนติดตั้ง (ทำครั้งเดียว ~15 นาที)

### 1) สร้าง Telegram bot เอาไว้รับแจ้งเตือน
1. เปิด Telegram ค้นหา **@BotFather** แล้วกด Start
2. พิมพ์ `/newbot` → ตั้งชื่อ → ตั้ง username (ต้องลงท้าย `bot`)
3. BotFather จะให้ **token** หน้าตาแบบ `123456789:AAExxxxxxxx` → **เก็บไว้**

### 2) หา chat id ของคุณ
1. ค้นหาบอทที่เพิ่งสร้าง แล้วกด **Start / พิมพ์อะไรก็ได้** ส่งหาบอท 1 ที
2. ค้นหา **@userinfobot** ใน Telegram แล้วกด Start → มันจะบอก **Id** ที่เป็นตัวเลข → นั่นคือ `chat_id` ของคุณ

### 3) สร้าง repo บน GitHub แล้วอัปโหลดไฟล์
1. ไปที่ github.com → **New repository** → ตั้งชื่อเช่น `dime-signal-bot`
   - แนะนำตั้งเป็น **Public** (Actions ฟรีไม่จำกัดนาที) — ในโค้ดไม่มีความลับอยู่แล้ว
2. กด **uploading an existing file** แล้วลากไฟล์ทั้งหมดจากโฟลเดอร์นี้ขึ้นไป
   - ⚠️ ต้องคงโครงสร้างโฟลเดอร์ `.github/workflows/signals.yml` ไว้
     (ถ้าลากทั้งโฟลเดอร์ไม่ได้ ให้สร้างไฟล์ทีละไฟล์ผ่านปุ่ม **Add file → Create new file**
     แล้วพิมพ์ path เป็น `.github/workflows/signals.yml`)

### 4) ใส่ความลับ (token / chat id)
ใน repo → **Settings → Secrets and variables → Actions → New repository secret**
สร้าง 2 อัน:

| Name | Value |
|------|-------|
| `TELEGRAM_TOKEN` | token จาก BotFather |
| `TELEGRAM_CHAT_ID` | id ตัวเลขจาก @userinfobot |

### 5) เปิดและทดสอบ
1. ไปแท็บ **Actions** → ถ้ามีแถบเขียวให้กด **enable workflows**
2. เลือก workflow **signal-bot** → กด **Run workflow** (รันเองทันที)
3. รอสักครู่ → ดู log ในแท็บ Actions ว่าเขียว ✅ และเช็คว่า Telegram เด้งเตือนไหม
   - ถ้าไม่มีหุ้นไหนเข้าเกณฑ์ จะไม่มีข้อความ (ปกติ) — ดู log จะเห็นบรรทัด `BUY/SELL/HOLD` ของแต่ละตัว

เสร็จแล้ว! หลังจากนี้บอทจะรันเองตามเวลาที่ตั้งไว้

## ปรับแต่ง

เปิดไฟล์ **`signal_bot.py`** ด้านบนสุด:
- `WATCHLIST` — รายการหุ้น (หุ้นไทยต้องลงท้าย `.BK` เช่น `SCB.BK`)
- `CONF_THRESHOLD` — ความมั่นใจขั้นต่ำที่จะเตือน (สูง = เตือนน้อยลงแต่คัดกว่า)
- `PORTFOLIO_SIZE`, `RISK_PER_TRADE` — ใช้คำนวณ "จำนวนหุ้นแนะนำ"
- `SUGGEST_OPTIONS` — เปิด/ปิดไอเดีย options สำหรับหุ้น US

เปลี่ยนเวลา/ความถี่: แก้ `cron` ในไฟล์ **`.github/workflows/signals.yml`**
(เวลาเป็น UTC, ไทย = UTC+7)

ทดสอบในเครื่องตัวเองก่อนได้ (ถ้ามี Python):
```bash
pip install -r requirements.txt
export DRY_RUN=1            # พิมพ์อย่างเดียว ไม่ส่งจริง (Windows ใช้ set DRY_RUN=1)
python signal_bot.py
```

## คำเตือนสำคัญ

- ราคาเป็นข้อมูล **ดีเลย์ ~15 นาที** (ฟรี) — ใช้กับสัญญาณราย day/swing พอได้ ไม่เหมาะ scalping
- สัญญาณเทคนิคทุกชนิด **ทำนายอนาคตไม่ได้** มองเป็นตัวช่วยคัดกรอง ไม่ใช่ระบบทำกำไรอัตโนมัติ
- **นี่ไม่ใช่คำแนะนำการลงทุน** ตัดสินใจและส่งคำสั่งเองทุกครั้ง
- GitHub Actions แบบตั้งเวลา จะถูกปิดอัตโนมัติถ้า repo ไม่มีความเคลื่อนไหว 60 วัน
  (บอท commit `state.json` ทุกครั้งอยู่แล้ว จึงนับเป็นความเคลื่อนไหว — ปกติไม่โดนปิด)

## อยากให้ "กดจากแจ้งเตือนแล้วยิงออเดอร์จริง" เลยจริงๆ?

Dime! ทำไม่ได้ (ไม่มี API รายย่อย) ทางเดียวคือเปิดพอร์ตที่ "มี API ส่งออเดอร์"
แยกต่างหาก เช่น **Alpaca / Interactive Brokers (IBKR)** สำหรับหุ้น US
หรือฝั่งไทยต้องใช้ **Settrade Open API** ผ่านโบรกที่เปิดให้ algo trade
(ต้องติดต่อโบรกขอเปิดสิทธิ์) — ถ้าจะไปทางนั้นบอกได้ เดี๋ยวต่อยอดให้
